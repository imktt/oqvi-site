## Зачем это существует

У каждого, кто держит серверы, рано или поздно наступает момент, когда
портфель вкладок с мониторингом перевешивает сами серверы.

**oqvi.ru** — это ответ на этот момент. Не SaaS, не платформа для «команд
до 10 человек», не стартап с pricing-страницей. Личная инфраструктура,
собранная под себя: без команд, без пользователей, без компромиссов.

## Что внутри

| | |
|:---|:---|
| 🛡 **Proxy Manager** | Собственное управление прокси: конфиги, профили и контроль подключений в одном месте |
| 📊 **Дашборд серверов** | Нагрузка, статус и здоровье всех серверов на одном экране |
| 🌐 **Подключение через веб** | Доступ ко всему из браузера — без лишних клиентов и настроек, откуда угодно |
| ⚡ **И многое другое** | Мониторинг сервисов, автоматизация и инструменты — всё, что нужно личному стеку |

## Про саму заглушку

Этот репозиторий — сайт-заглушка oqvi.ru. Один файл `index.html`.

- 🌑 тёмная тема с градиентными блобами и сеткой на фоне

- 📦 ноль зависимостей и ноль сборщиков — открыл и работает
